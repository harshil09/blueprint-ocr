# Figure crop evaluation set

This folder holds the **labeled test set** used to measure figure-cropping quality.

## Layout

```
eval/
  manifest.json          # Index of all labeled samples
  samples/               # Optional per-sample label files (see below)
  reports/               # Generated by run_figure_eval.py
```

## Manifest format

Each entry in `manifest.json`:

| Field | Description |
|-------|-------------|
| `id` | Unique sample id |
| `source_path` | Absolute or manifest-relative path to PDF/PNG/TIFF |
| `page_index` | Zero-based page index |
| `document_tags` | Tags for grouping (`cad_wide`, `scanned_pdf`, etc.) |
| `expected.bbox_xyxy` | `[x0, y0, x1, y1]` ground-truth crop in page pixels, or `null` |
| `expected.min_iou` | Minimum IoU vs `bbox_xyxy` when labeled |
| `expected.max_text_overlap` | Max allowed OCR text inside crop |
| `expected.max_area_ratio` | Max crop area as fraction of page |
| `expected.expect_figure` | `false` for text-only pages |
| `expected.expected_crop_profile` | Optional expected `CropProfile` name |

## Failure categories

| Category | Meaning |
|----------|---------|
| `good` | All checks passed |
| `full_page_win` | Crop too large / near full page |
| `text_in_crop` | Too much OCR text in bbox |
| `too_tight` | Crop smaller than expected |
| `too_loose` | Crop larger than expected |
| `wrong_view` | Wrong region (low IoU) |
| `no_figure` | Expected figure but none emitted |
| `unexpected_figure` | Figure emitted when none expected |
| `low_confidence` | Figure below confidence threshold |
| `profile_mismatch` | Wrong crop profile selected |
| `skipped` | Source file missing |

## Run evaluation

```bash
python scripts/run_figure_eval.py
python scripts/run_figure_eval.py --manifest eval/manifest.json --output eval/reports
```

Output: `eval/reports/eval_report.json` with per-page results and failure counts.

## Adding labels

1. Run the pipeline on a document and note the page size (from logs).
2. Draw the desired crop rectangle in an image editor or use bbox overlay in Streamlit.
3. Set `bbox_xyxy` in `manifest.json` to `[x0, y0, x1, y1]` in page coordinates.
4. Re-run `run_figure_eval.py` — IoU and failure category will update.
